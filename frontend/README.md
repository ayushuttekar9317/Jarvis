# 🤖 J.A.R.V.I.S. // Frontend Interface

A futuristic, high-performance React application designed with rich sci-fi aesthetics, glassmorphism, dynamic audio-reactive canvas waveforms, and interactive neural diagnostics.

## 🚀 Tech Stack

- **React 18**: Dynamic UI component hierarchy.
- **Vite 6**: Next-generation lightning-fast frontend tooling.
- **Vanilla CSS (Design Tokens)**: Tailored HSL themes, neon glows, glassmorphism, responsive grid layouts.
- **HTML5 Canvas**: Hardware-accelerated real-time neural frequency visualizer.

## 🛠️ Available Scripts

In the `frontend` directory, you can run:

```bash
# Start local development server (http://localhost:3000)
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## ✨ Key Features

- **Arc Reactor & Neural Core**: Interactive overdrive states with orbital ring rotation and multi-axis flux gauges.
- **Dynamic Holographic HUD Themes**: Switch in real-time between Cyan-01, Quantum Purple, Solar Amber, and Emerald Matrix.
- **AI Command Console**: Interactive terminal shell with built-in commands (`status`, `scan`, `optimize`, `protocols`, `theme`, `clear`, `ping`, `whoami`).
- **Telemetry Matrix**: Real-time live simulated CPU, memory, bandwidth, and synapse throughput monitors.
- **System Protocols**: Toggleable quantum encryption and defensive sentinel matrix switches.
